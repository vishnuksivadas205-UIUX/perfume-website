MAJESTIC PARFUMS — HOMEPAGE

Files:
- index.html
- style.css
- script.js
- assets/hero-reference.jpg

How to run:
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html with Live Server, or open it directly in your browser.

Font:
- Playfair Display is used for the main heading and brand wordmark.
- DM Sans is used for navigation and body text.
- The fonts load from Google Fonts, so an internet connection is needed.

Important image note:
The supplied reference is a screenshot, not a clean hero photograph. The included
hero-reference.jpg is cropped from that screenshot. The CSS uses a warm overlay
on the left to cover the screenshot's baked-in heading and button, then recreates
those elements as editable HTML text. For a pixel-closer result, replace
assets/hero-reference.jpg with the original clean perfume hero photograph
(without any text or navbar), keeping the same filename.
